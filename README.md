# PT Ontiyus Karya Mulia - Internal Portal System

Portal informasi dan sistem manajemen internal yang dikembangkan untuk **PT Ontiyus Karya Mulia**. Proyek ini merupakan hasil kolaborasi dengan **Universitas Gadjah Mada (UGM)** untuk mendigitalisasi proses internal dan manajemen data perusahaan.

![Logo](public/ontiyus-logo-full.png)

## 📄 Deskripsi

Sistem ini dirancang untuk memfasilitasi kebutuhan internal PT Ontiyus Karya Mulia, mencakup:
- Profil dan informasi perusahaan
- Manajemen data internal
- Sistem informasi terintegrasi
- Workflow operasional yang efisien

**Note:** Website publik dapat diakses di [pt-ontiyus-karya-mulia.vercel.app](https://pt-ontiyus-karya-mulia.vercel.app)

## 🛠️ Teknologi

Dibangun menggunakan teknologi web modern untuk performa dan skalabilitas tinggi:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Package Manager:** PNPM

## 🤝 Kolaborasi

Proyek ini dikembangkan dibawah naungan dan kerja sama dengan:
**Universitas Gadjah Mada (UGM)**

## 🚀 Getting Started

Prerequisites: Node.js & PNPM installed.

```bash
# Clone repository
git clone https://github.com/arapcihuy/pt-ontiyus-karya-mulia.git

# Install dependencies
pnpm install

# Run development server
pnpm dev
```

## 📂 Struktur Proyek

- `/app`: Halaman dan routing (Next.js App Router)
- `/components`: Komponen UI reusable 
- `/lib`: Utilitas dan konfigurasi library
- `/public`: Aset statis (gambar, logo)
